# Мобильное приложение

## Что за приложение?
Простое TODO приложение

## Что умеет
Управлять тасками: создавать, удалять, изменять

## Какие экраны должны быть
Имеет следующие экраны:
- Основной экран с тудушками, общей статистикой
- Экран создания и редактирования тудушки

## Какая навигацию должна быть

- Нужно уметь из основного экрана перейти в экран создания новой таски
- Нужно уметь вернуться обратно на основной экран

## Требования к реализации

- Реализация должна быть с хорошим разделение по дирректориям по принципу layer first
- С навигацией через Navigator 2.0


# Web приложение

## Что за приложение?
Это тоже самое, что и мобильное приложение, только имеет некоторые особенности, связанные с WEB

## Какие особенности?
- Адаптивный UI. Нужно сделать так, чтобы экран был адаптивный в зависимости от размера экрана.
- Шорткаты. Нужно добавить шорткаты для быстрого и удобного использования приложения на компьютере

# Реализация

## Хранение данных

Приложение поддерживает несколько способов хранения данных в зависимости от платформы:

- **Нативные платформы**: Используется MethodChannel для взаимодействия с нативным хранилищем
- **Web (JS Interop)**: Используется JavaScript interop для хранения данных в localStorage
- **Web (WASM)**: Опционально можно использовать WebAssembly для хранения данных в localStorage

## WASM Реализация

Проект включает альтернативную реализацию TodoService с использованием Rust и WebAssembly:

- Код Rust находится в директории `rust_wasm/`
- Для сборки WASM модуля используйте скрипт `./build_wasm.sh`
- Подробная документация в `rust_wasm/README.md` и `docs/todo_wasm_service_plan.md`

Для переключения между JS Interop и WASM реализациями:

1. Соберите WASM модуль с помощью `./build_wasm.sh`
2. Раскомментируйте строку загрузки WASM в `web/index.html`
3. Обновите условный импорт в `lib/data/services/todo_service.dart`
